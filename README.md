# Snowy Circuit — Christmas Kart

HTML, CSS, JavaScript로 만든 크리스마스 테마의 비공식 팬 카트 레이싱 게임입니다. 외부 이미지나 오디오 파일 없이 Canvas와 Web Audio로 그래픽과 음악을 만듭니다.

## 실행

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 인터넷 연결이 없으면 시스템 글꼴을 사용하며 게임은 정상 작동합니다.

## 조작

- ↑ / W: 가속, ↓ / S: 브레이크
- ← → / A D: 방향 조작
- Space: 아이템 사용
- P: 일시 정지 / 재개
- 터치 화면: 화면 아래 버튼 사용

마리오, 루이지, 피치, 요시, 키노피오, 쿠파 중 한 명을 선택해 AI 5명과 3바퀴를 경쟁합니다. 선물 상자를 획득해 로켓 부스트, 눈꽃 얼리기, 추적 눈덩이를 사용하세요. 도로 밖에서는 속도가 감소하고 다른 카트와 충돌하면 감속합니다. 음악은 시작 또는 사운드 버튼을 누른 뒤 재생됩니다.

Nintendo와 관련 없는 비공식 팬 프로젝트입니다. 캐릭터 이름은 각 권리자에게 귀속됩니다. 그래픽은 코드로 직접 그린 단순화된 표현입니다.
